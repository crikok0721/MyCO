## Status rules

- `Verified Implemented` requires current code, relevant tests, and required visual/system evidence.
- `Implemented Unverified` means code and automated evidence exist but a required real environment gate is missing.
- `Partial`, `Regressed`, `Pending`, `Superseded`, `Rejected`, and `Unknown` are not interchangeable. A historical document claiming completion never upgrades the current status.

# MyCO 0.99.1

MyCO 0.99.1 packages the current UI, localization, calibration, message-identity,
and factory-reset maintenance baseline.

## Highlights

- Unified light/dark preview bubble geometry and startup option spacing.
- Assigned a separate identity to each legal Assistant progress and final
  message unit.
- Added Japanese (`ja-JP`) Manager UI and README support.
- Refreshed calibration/onboarding surfaces with the shared minimal desktop
  design language.
- Added a localized factory reset that restores the first-launch state safely.

## Release integrity

- Windows x64 self-contained ZIP
- Authenticode SHA-256 signatures on project-owned binaries
- Signer: `CN=Crikok` (ephemeral self-signed release certificate)
- SHA-256 archive checksum
- SPDX 2.2 SBOM
- GitHub build-provenance attestation

The certificate is not publicly trusted by Windows; SmartScreen warnings may
remain. Verify the ZIP checksum, public certificate, source tag, SBOM, and
attestation. See `security/CODE_SIGNING.md`.

## Requirements

- Windows 10/11 x64
- Official Codex / ChatGPT Desktop installation

## Upgrade note

Legacy `%APPDATA%\MyCodex` migration behavior is unchanged. The package keeps
the existing local-only, fail-closed, and reversible runtime boundaries.

# MyCO 0.99.0

MyCO 0.99.0 is the first consolidated MyCO-branded public release candidate.
It includes the Beta stabilization work, role-first Manager redesign,
private-pipe-first Desktop integration, reversible conversation styling, and
the synchronized Chinese and English project documentation.

## Release integrity

- Windows x64 self-contained ZIP
- Authenticode SHA-256 signatures on project-owned binaries
- Signer: `CN=Crikok`
- RFC 3161 timestamp
- SHA-256 archive checksum
- SPDX 2.2 SBOM
- GitHub Actions build-provenance attestation

The Authenticode certificate is self-signed and is not publicly trusted by
Windows. SmartScreen can still show an unknown-publisher or reputation warning.
The release uses an ephemeral certificate, so its fingerprint is specific to
this release and does not establish publisher continuity across versions.
See `security/CODE_SIGNING.md` before running the package.

## Requirements

- Windows 10/11 x64
- An official Codex / ChatGPT Desktop installation

## Upgrade note

Legacy `%APPDATA%\MyCodex` data is copied to `%APPDATA%\Myco` only when the new
directory does not already exist. Existing MyCO data is not overwritten and
the legacy directory is not deleted.

# MyCO 0.99.2

MyCO 0.99.2 is the Phase 3 Beta stability release for the Windows x64
self-contained Manager and Runtime package.

## Highlights

- Shared Home/Appearance preview bubble geometry with matching Assistant/User
  chrome, adaptive Assistant content sizing, and the Whole-mode long-Markdown
  stretching-shell repair.
- Schema 7 baseline-plus-delta geometry with independent role offsets; the
  current safe baseline resolves to a 35px avatar and -4px User avatar Y at
  zero.
- First-run `菲叶子` Assistant identity with the packaged `MyCO-logo.png`
  default avatar; existing, migrated, and custom avatars remain untouched.
- Per-MyCO-process first-minimize notification with the exact title
  `It's MyCO!!!!!`, localized body text, a native ToastGeneric notification with
  a packaged 64px blue information mark, and BalloonTip fallback.
- Transactional MyCO-owned startup/association entries, four-language onboarding
  cleanup, and the current Runtime/configuration regression repairs.

## Release integrity

- Windows 10/11 x64 self-contained ZIP
- Authenticode SHA-256 signatures on project-owned binaries
- Signer: `CN=Crikok` (ephemeral self-signed release certificate)
- SHA-256 archive checksum
- SPDX 2.2 SBOM
- GitHub build-provenance attestation

The certificate is not publicly trusted by Windows; SmartScreen warnings may
remain. Verify the ZIP checksum, public certificate, source tag, SBOM, and
attestation. See `security/CODE_SIGNING.md`.

## Requirements

- Windows 10/11 x64
- Official Codex / ChatGPT Desktop installation

## Known validation limits

The release preserves the documented fail-closed and privacy boundaries. Real
Codex conversation visuals, Windows Shell notification rendering, DPI coverage,
and the full fresh-machine startup matrix remain environment-dependent checks
for the user's disposable acceptance session; automated tests do not replace
those observations.

## Upgrade note

Legacy `%APPDATA%\\MyCodex` migration behavior is unchanged. The package keeps
the existing local-only, fail-closed, and reversible runtime boundaries.
